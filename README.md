## Demo web automática

Cada push a `main` prepara y publica el juego en GitHub Pages una vez activado
**Settings → Pages → Source: GitHub Actions**. URL prevista:
**https://eldoig.github.io/Wamai/**.

Ver [activación, pruebas locales, archivos publicados y requisitos del plan](docs/demo-web.md).
La publicación se prepara directamente desde `Project/`; no cambia el trabajo
habitual con RPG Maker MZ ni requiere exportar manualmente en cada actualización.

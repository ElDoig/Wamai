## Gráficos de personajes

El sprite de mapa actual de Miwa (Actor 1) es `Project/img/characters/$Miwa_Walk.png`, con índice de personaje `0`.

- PNG original con transparencia: 192 × 256 píxeles.
- Cuadrícula de 3 columnas × 4 filas; cada fotograma mide 64 × 64 píxeles.
- Direcciones por fila: abajo, izquierda, derecha y arriba.
- El prefijo `$` indica a RPG Maker MZ que la hoja contiene un solo personaje.
- Esta hoja es para caminar por el mapa. Los retratos y los battlers de combate lateral se configuran por separado.

Los archivos anteriores de Miwa se conservan para referencia. Para comprobar el gráfico actualizado, iniciar una partida nueva; las partidas guardadas pueden conservar el gráfico anterior. Si el editor estaba abierto durante la actualización, volver a abrir el proyecto antes de guardar la base de datos.
